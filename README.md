# ระบบแบบทดสอบความสามารถพนักงาน — Wesco

เว็บแอปสำหรับให้พนักงานทำแบบทดสอบความสามารถ พร้อมระบบตัดเกรดอัตโนมัติ และหน้าหลังบ้านสำหรับผู้ดูแล
ออกแบบให้ใช้งานบน **มือถือเป็นหลัก** และปรับหน้าจอให้เหมาะกับแท็บเล็ต/คอมพิวเตอร์อัตโนมัติ

ข้อมูลข้อสอบตั้งต้นแปลงมาจากไฟล์ `แบบทดสอบพนักงาน.xlsx` ครบทั้ง **11 หัวข้อ · 63 ข้อ**

### ความสามารถเพิ่มเติม

- **คะแนนภาคปฏิบัติ** — ตรงกับช่อง *Supervisor Verify Performance (เต็ม 10)* ในไฟล์ Excel เดิม โดย Admin เป็นผู้กรอกให้
- **คำถามแบบเขียนตอบ** — Admin ตรวจให้คะแนนเองได้ (ใช้กับแบบทดสอบภาคปฏิบัติ TH-BP-07.021)
- **เอกสารอ้างอิงระหว่างสอบ** — รูป Work Order / Wire Run List / ตาราง Cosmetic เปิดดูและซูมอ่านได้บนมือถือ
- **จับเวลา** ต่อหัวข้อ · **สลับลำดับข้อ** · **บันทึกคำตอบอัตโนมัติ** (ปิดแอปแล้วกลับมาทำต่อได้)
- เฉลยรายข้อหลังส่งคำตอบ · ประวัติการสอบ · ส่งออกผลเป็น CSV (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน)

## ติดตั้งและขึ้นระบบจริง (Cloudflare)

ต้องมี **Node.js 18+** และบัญชี Cloudflare (แพลนฟรีใช้ได้)

### 1) ติดตั้ง dependency และเข้าสู่ระบบ Cloudflare

```bash
npm install
npx wrangler login
```

### 2) สร้างฐานข้อมูล D1

```bash
npx wrangler d1 create wesco_assessment
```

คำสั่งนี้จะพิมพ์ `database_id` ออกมา — ให้ **คัดลอกไปวางใน `wrangler.toml`** แทนที่คำว่า `PASTE_YOUR_D1_DATABASE_ID_HERE`

```toml
[[d1_databases]]
binding = "DB"
database_name = "wesco_assessment"
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"   # <-- วางตรงนี้
```

### 3) สร้างตารางและใส่ข้อสอบตั้งต้น

```bash
npm run db:init
npm run db:seed
```

### 4) อัปโหลดขึ้น Cloudflare Pages

```bash
npx wrangler pages project create wesco-assessment --production-branch main
npm run deploy
```

จะได้ URL หน้าตาประมาณ `https://wesco-assessment.pages.dev`

> **ถ้าเปิดเว็บแล้วขึ้นว่า "ยังไม่ได้ผูกฐานข้อมูล D1"**
> ให้เข้า Cloudflare Dashboard → Workers & Pages → เลือกโปรเจกต์ → **Settings → Bindings → Add → D1 database**
> ตั้ง Variable name = `DB` เลือกฐานข้อมูล `wesco_assessment` แล้ว Deploy ใหม่อีกครั้ง

### 5) สร้างบัญชีผู้ดูแลคนแรก

เปิด `https://<โดเมนของคุณ>/admin.html` ระบบจะแสดงฟอร์ม **"ตั้งค่าระบบครั้งแรก"** ให้ตั้งชื่อผู้ใช้และรหัสผ่านเอง
หน้านี้ใช้ได้ครั้งเดียว — เมื่อมีผู้ดูแลในระบบแล้วจะปิดตัวเองอัตโนมัติ

เสร็จแล้วส่งลิงก์หน้าแรกให้พนักงานได้เลย

## เชื่อมกับ GitHub (Deploy อัตโนมัติทุกครั้งที่แก้โค้ด)

```bash
git remote add origin https://github.com/TopMaha/Oil_W.git
git push -u origin main
```

จากนั้นใน Cloudflare Dashboard → Workers & Pages → Create → **Pages → Connect to Git** → เลือก repo นี้ แล้วตั้งค่า:

| ช่อง | ค่าที่ใส่ |
|---|---|
| Framework preset | None |
| Build command | *(เว้นว่าง)* |
| Build output directory | `public` |

อย่าลืมเพิ่ม D1 binding ชื่อ `DB` ในหน้า Settings → Bindings ของโปรเจกต์ด้วย

## การใช้งานหลังบ้าน

เข้าที่ `/admin.html`

| เมนู | ทำอะไรได้ |
|---|---|
| **ภาพรวม** | จำนวนพนักงาน/ข้อสอบ/การสอบ · คะแนนเฉลี่ย · สัดส่วนเกรด · ผลแยกตามหัวข้อ · รายการรอตรวจ |
| **ข้อสอบ** | เพิ่ม/แก้ไข/ลบหัวข้อ · จัดการคำถามและตัวเลือก (เลือกข้อที่เป็นเฉลย) · แนบรูป · เพิ่มเอกสารอ้างอิง |
| **ผลสอบ** | กรองตามหัวข้อ/เกรด/รอตรวจ · ค้นหาพนักงาน · **กรอกคะแนนภาคปฏิบัติ** · ตรวจข้อเขียน · ส่งออก CSV |
| **พนักงาน** | ดู/แก้ไข/ระงับ/ลบพนักงาน · ดูคะแนนเฉลี่ยรายคน |
| **ตั้งค่า** | เกณฑ์เกรด A/B · เปิด-ปิดการสอบซ้ำ · แสดงเฉลย · เปิด-ปิดรับลงทะเบียน · จัดการบัญชีผู้ดูแล |

### เรื่องที่ควรรู้

- **แก้เกณฑ์เกรดแล้วผลเก่าจะถูกคำนวณใหม่ให้อัตโนมัติ** ทุกครั้งที่กดบันทึก
- หัวข้อที่ตั้ง **คะแนนภาคปฏิบัติ > 0** จะยังไม่ออกเกรดจนกว่า Admin จะกรอกคะแนนส่วนนั้น
  (พนักงานเห็นคะแนนปรนัยทันที แต่เกรดจะขึ้นว่า "รอตรวจ")
  ถ้าไม่ต้องการใช้ ให้ตั้งค่าเป็น `0` เกรดจะออกทันทีที่ส่งคำตอบ
- **การสลับลำดับ** จะสลับเฉพาะลำดับข้อ ไม่สลับลำดับตัวเลือก เพราะมีข้อที่ตัวเลือกเป็น "ถูกทุกข้อ"
- ลืมรหัสผ่านผู้ดูแล — รีเซ็ตด้วย `node scripts/make-admin.mjs --user admin --pass "รหัสใหม่"` แล้วรัน SQL ที่ได้

## ความปลอดภัย

- **ตรวจคำตอบที่เซิร์ฟเวอร์เท่านั้น** — เฉลยไม่เคยถูกส่งไปที่เบราว์เซอร์ระหว่างทำข้อสอบ
- รหัสผ่านผู้ดูแลเก็บเป็น **PBKDF2-SHA256 150,000 รอบ** พร้อม salt เฉพาะราย ไม่มีการเก็บรหัสผ่านจริง
- ทุกคำสั่งฐานข้อมูลใช้ prepared statement กัน SQL injection
- พนักงานเข้าถึงได้เฉพาะผลสอบของตัวเอง · โทเคนพนักงานใช้กับ API หลังบ้านไม่ได้
- จำกัดการเดารหัสผ่านผู้ดูแล (ผิดเกิน 8 ครั้งใน 15 นาที จะถูกพักชั่วคราว)
- เซสชันหมดอายุเอง — พนักงาน 12 ชั่วโมง · ผู้ดูแล 8 ชั่วโมง

> **หมายเหตุเรื่องการยืนยันตัวตนพนักงาน:** ตามที่ตกลงไว้ พนักงานเข้าระบบด้วย**รหัสพนักงานอย่างเดียว** ไม่มีรหัสผ่าน
> เหมาะกับการสอบที่มีผู้คุมสอบอยู่ด้วย ถ้าต้องการกันการสวมรอยในอนาคต สามารถเพิ่ม PIN 4-6 หลักได้ภายหลัง
